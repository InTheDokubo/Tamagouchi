## 基本ルール

- 1ターンの基本行動回数は1回、基本ドローは4枚、手札上限は9枚です。
- 「続けて行動」は使用時に行動権を1回復します。
- 「1回のみ」のカードは、使用するとその戦闘中は山札へ戻りません。
- カード自身の反動ダメージではHP1未満にならず、反動だけで戦闘不能にはなりません。
- 回復カードは最大HPに対する割合で回復し、小数点以下は切り上げます。カード強化で回復割合も上昇します。
- 物理攻撃を同じターンに重ねるとコンボ補正が上がります。多段攻撃は各ヒットごとにコンボが進み、後半ほど威力が上がります。
- 魔力型カードは固有資源「一時魔力」を獲得・消費します。一時魔力は敵を倒しても持ち越し、ショップまたは秘伝の改造へ到達すると0になります。
- 炎上は敵行動後に蓄積値ぶんのダメージを与えて2減少します。炎上中の敵へ炎上カードを重ねると「引火爆発」が発生し、現在の炎上を消費して敵の最大HP30%を直接削り、一時魔力10を得ます。同じ敵へさらに炎上を重ねると以後は「再引火」となり、最大HP20%を直接削って現在の一時魔力を1.5倍（端数切り上げ）にします。どちらも爆発後に新しい炎上を付与します。脆弱は上限なく重複し、1スタックにつき次の攻撃のダメージが+50%され、その攻撃で全スタックを一括消費します。多段攻撃では最初の1ヒットだけに全スタックが乗ります。弱化は敵の次の攻撃を25%下げます。

## ジョブ

各ジョブは5枚の専用初期デッキを持ちます。敗北後の継承強化は初期能力へ別途加算されます。

### 体力型 🐻

- 初期能力: 最大HP65・攻撃5・魔力5
- 初期デッキ: パンチ、防御2枚、絆創膏、ボディプレス
- 生命の殻: 戦闘開始時、最大HPの12%（最低8）のブロックを得ます。
- 自然治癒: 各ターン終了時、最大HPの8%（最低5・最大14）を回復します。
- 血潮の鎧: カード効果でHPを消費するたび、消費量の50%のブロックを即座に得ます。血の盟約中は100%になります。
- 区間防壁: 体力型のブロックはターン終了・敵撃破・道中イベントでも消えず、5戦チェックポイントのショップ（10勝時は秘伝の改造）へ到達するまで残ります。チェックポイント到達時に0へ戻ります。

#### 体力型の設計

体力型は「高い最大HP・回復・ブロックで堅実に戦う状態」と、「蓄えたHPを大ダメージへ変えるリスク状態」を往復するジョブです。

- 堅実側: 回復でHPを蓄え、生命の殻や防御カードで敵の大技を受けます。最大HPが高いほど自然治癒とHP参照カードも強くなります。
- リスク側: ボディプレス、生命転換、プレスはHPを消費して大きなダメージを出します。HP消費はHP1で止まり、血潮の鎧で一部がブロックへ変わるため、攻めながら次の攻撃へ備えられます。
- 復帰: 絆創膏、底力、大回復などの割合回復で安全圏へ戻ります。最大HPを伸ばしても回復カードの価値が落ちず、再びHPを火力へ変換できます。
- 判断軸: 敵の予告攻撃、手札の回復量、現在HPから「守る・回復する・使い切る」を毎ターン選びます。

### 攻撃型 🐯

- 初期能力: 最大HP50・攻撃8・魔力5
- 初期デッキ: パンチ、ジャブ、防御、キック、激怒
- 先手必勝: 戦闘の最初のターンだけ行動回数が2回になります。
- 連撃の呼吸: 各ターン、物理攻撃のコンボが初めて3以上になったとき、行動権を1回復してカードを1枚引きます。1ターンに1回だけ発動します。
- クロスカウンター: 敵の攻撃を受けるとき、10%の確率で完全回避し、その攻撃の火力1.5倍で反撃します。

#### 攻撃型の設計

攻撃型は「起点・連携・決め技」の順にカードをつなぎ、1ターンへ火力を集中させるテンポ型ジョブです。

- 起点: ジャブは低威力でコンボを準備します。フェイントは攻撃判定を持たず、行動権を消費せずに脆弱を無制限に積み上げます。
- 連携: 連続拳や乱れ打ちは1枚で複数ヒットを稼ぎ、連撃の呼吸を早く発動させます。
- 決め技: キック、本気パンチ、とどめの一撃などを高いコンボ補正や脆弱へ重ねます。
- リスク: 軽い攻撃だけでは総火力が不足し、大技を早く切るとコンボ補正を失います。敵の予告を見ながら攻め切るか、防御を挟むか判断します。
- デッキ構築: 起点カードを増やしすぎず、コンボを稼ぐカード・手札を補充するカード・決め技の比率を整えることが重要です。

### 魔力型 🦉

- 初期能力: 最大HP50・攻撃5・魔力8
- 初期デッキ: パンチ2枚、防御、プチ魔法、バリア
- 一時魔力: 魔力型カードごとに1～4獲得します。敵を倒しても次の戦闘へ持ち越され、ショップまたは秘伝の改造へ到達すると0になります。
- 魔力型の設計: 通常魔力を参照する攻撃・防御は扱いやすく、一時魔力を貯めて魔道書による手札循環、魔力解放、時間操作、残響など固有の特殊効果へ変換します。残響・魔力炉・極・魔導核は重ねがけでき、炎上は引火爆発から再引火へつなげられます。貯め続けるか、連携へ変換するかが判断軸です。
- 秘奥術: 戦闘画面の一時魔力パネルから、行動権を使わず発動できます。各術式は1戦闘1回です。
  - 魔導転写（一時魔力3）: カードを2枚引きます。
  - 位相転換（一時魔力5）: 次の敵攻撃を完全無効化し、その火力の半分（最大8）を一時魔力へ変換します。
  - 時間圧縮（一時魔力8）: 行動権を1回復し、カードを2枚引きます。

## プレイヤーレベルとカード解放

- ゲーム終了時、撃破数と累計与ダメージに応じたプレイヤー経験値を獲得します。
- 経験値とプレイヤーレベルは `localStorage` に保存され、次の挑戦以降も維持されます。
- レベルアップすると新しいカードが報酬・育成ドラフト・ショップの候補へ恒久的に追加されます。
- リザルトでは獲得EXP、現在レベル、次のレベルまでの進捗、新たに解放したカードを確認できます。
- 解放カードは数値効率だけでなく、コンボ開始値、魔力獲得、HP消費、回復、カード連鎖といった戦闘ルールそのものを変える「構築の核」です。
- Lv2からLv20まで、レベルが1上がるたびに攻撃型・魔力型・体力型へ1枚ずつ、合計3枚の新カードが解放されます。

## カード図鑑とデッキ確認

- タイトル画面の「カード図鑑」から、共通・体力・攻撃・魔力プランを切り替えて全125枚を確認できます。
- 解放済みカードは名前と効果を表示し、未解放カードは暗転・鍵アイコン・必要プレイヤーレベルで区別します。
- 戦闘画面右上のカード枚数パネルを押すと、全デッキ・山札・捨て札・除外札の内容を確認できます。
- 山札は内容だけを名前順で表示し、次に引く順番は公開しません。強化済みカードと秘伝改造済みカードもバッジで判別できます。
- 道中イベント画面右上の「デッキ確認」からも、イベントを選ぶ前に現在の構築を確認できます。

## 敵の進化と道中イベント

- 敵のHP・攻撃の伸びは緩やかにし、後半の難度は単純な数値ではなく行動パターンで作ります。
- 通常敵は「狩人・豪腕・幻術・再生・群体」の5系統。エリートは「守護者・暗殺者」、ボスは「竜王・不死鳥・巨神」の3系統です。
- 連撃、吸収、回復、呪い、防御、自己強化など、敵ごとに異なる周期で行動します。予告表示には合計火力や攻撃回数も表示されます。
- すべての敵はHP半減時に形態変化し、攻撃強化・障壁・再生など固有の反応を行います。
- Lv6以降の敵には「装甲・再生・狂化」の変異特性が確率で付きます。変異内容は戦闘画面のステータス欄で確認できます。
- ボス撃破時は最大HP+3、攻撃・魔力+1、BP+25、HP50%回復の「覚醒」報酬を得ます。
- 道中イベントは2勝ごとに発生し、回復・カード強化・デッキ圧縮・型カード獲得・ハイリスクな永続強化など12種類から選択します。
